# 佣金系数计算

## 业务事实

* 一个订单包含多个产品，每个产品有合同额 和 实际收入金额，订单分区域
* 产品分产品线、产品系列，产品线可设置奖金池奖励成单的负责人
* 订单负责人分区域，有角色，有上下级关系。
* 每个员工有合同收入额目标和实际收入金额目标
* 员工除了获得订单佣金外还能获得奖金池奖励

## 计算内容
1. 员工的合同佣金系数（实际合同额/目标合同额）、收入佣金系数（实际收入额/目标收入额）
2. 奖金池分成（按成单顺序分）

## 计算输入
1. 订单
2. 员工角色
3. 区域
4. 产品
5. 设置在1-4上的规则

## 规则

### 通用规则
1. 时间因子：成单时间在Q1～Q4乘以1～2的系数
2. 产品因子：根据成单的产品乘以1～2的系数

### 销售部分的规则

销售职责（角色）：SS，PS，AD、AS

1. SS分账：只要成单产品是指定的几个产品，SS就会分账
2. PS分账： 佣金分账公式（系数*区域*订单分类），奖金池分账规则（均分或所有）

人员关系：
1. AD与AS一对多
2. SS与AS一对多
AS成单按1:1分给SS，SS成单需要平分给AS。

佣金系数：
按指标额分高业绩区间、正常业绩区间、低业绩区间，每个区间按达成率设置佣金系数。

佣金特殊规则：可以设置一些特殊规则。

销售人员的奖金池分账规则：产品线设置奖金池总额，并设置分账规则，分账规则与销售角色和订单属性有关。

### 部门A的规则

1. 佣金系数按角色和达成率设置系数
2. 奖金池规则： 按产品线和角色设置奖金池总额，规则与角色和具体产品有关

### 计算方法

1. 全量计算
2. 按人员计算
3. 按订单计算
